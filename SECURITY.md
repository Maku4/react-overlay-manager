# Security policy

## Reporting a vulnerability

Private vulnerability reporting is not enabled for this repository yet, so GitHub does not offer a private report form here. Until it is enabled:

1. Open an issue that only asks for a private security contact. Do not include the vulnerability, affected code, a proof of concept or anything else that describes the problem.
2. Wait for a maintainer to reply with a private way to send the details.

Once private reporting is enabled, the repository's **Security** tab shows a **Report a vulnerability** button. Use that instead of an issue.

Do not describe a vulnerability in a public issue, pull request or discussion.

In the private report, include the affected package and version, steps to reproduce and the impact you expect. Check the latest published version first if you can.

## Scope

This policy covers `@react-overlay-manager/core` and `@react-overlay-manager/devtools`.

`@react-overlay-manager/devtools` shows overlay props in the page by design while it runs in development.
