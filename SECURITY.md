# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:

https://github.com/Maku4/react-overlay-manager/security/advisories/new

Do not open a public issue, pull request or discussion for a vulnerability.

Include the affected package and version, steps to reproduce and the impact you expect. Check the latest published version first if you can.

## Scope

This policy covers `@react-overlay-manager/core` and `@react-overlay-manager/devtools`.

`@react-overlay-manager/devtools` shows overlay props in the page by design while it runs in development.
